# Multi-reference demonstration data

These three small CSV files are a frozen local reference set for the thesis demonstration.
They represent country/capital identifiers, a country-to-president index, and presidential
terms as separate references. They are intentionally split so that the final answer cannot be
obtained from one table alone.

The benchmark only asks dates covered by the rows in this frozen set. It is not a live political
dataset and must not be used to answer current-office questions.
